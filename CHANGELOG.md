# Changelog

## 0.2.0 — 2026-11-01

- Rendering ecosystem: The complete Fiber API is available at `/fiber`; `/native` and `/testing` expose the corresponding foundation entry points. The unmodified 228-file reference tree preserves its core, reconciler, hooks, native implementation, test renderer, lint rules, tests, examples and docs.
- LuxLeaf scene tools: Versioned scene documents, strict transforms/material validation, skeleton-aware model cloning, reference-counted asset cache, animation playback, adaptive DPR, error boundaries and PNG capture.
- Developer workbench: Local embedded GLB import, scene JSON editor, animation controls, model replacement resource disposal and a real rendering acceptance page.
- Add source-inclusive package archives, foundation hash checks, and GitHub Packages publishing/consumer installation workflows.

Initial limited workbench release. It did not establish complete upstream parity.
